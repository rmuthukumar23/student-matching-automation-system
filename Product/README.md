# Product Build

This directory contains the archived Android build of the Students for Students tutor-matching application.

## Included File

`SOS Admin App.apk` is the installable Android package produced for the original project.

## Before Installing

This is an archived student-project build, not a maintained production release. It may depend on external authentication, Google Sheets, or web services that have changed since the original implementation.

Only install APK files on devices where you understand and accept the security implications. Do not use real student data, production credentials, or private operational information when testing this archived build.

## Installation

1. Transfer `SOS Admin App.apk` to an Android device.
2. Open the APK from the device.
3. If required, allow installation from the relevant source in Android settings.
4. Complete the installation.

For the project context, workflow, documented outcomes, and development evidence, return to the [main README](../README.md) or review the [development documentation](../Development/README.md).
