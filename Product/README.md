# Android build

`SOS Admin App.apk` is the archived Android build of the Students for Students admin app.

The app depends on the original external Google Apps Script services, so the APK may no longer work on its own.

If you install it, use a test device and do not enter real student data or credentials.

See the [main README](../README.md) for the project overview or [`Development/`](../Development/) for the original documentation.
